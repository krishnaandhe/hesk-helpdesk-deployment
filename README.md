# HESK Helpdesk Deployment

## Overview
Ticketing system implemented for internal IT support operations.

## Use Case
Track IT issues, improve SLA response time, centralized IT support.

## Installation
1. Setup IIS + PHP
2. Configure MySQL Database
3. Setup HESK Files
4. Configure Email Settings

## Architecture
User -> Web Portal -> HESK App -> MySQL DB

## Business Impact
Improved IT support efficiency and tracking.
